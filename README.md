# 🤖 Adaptive Knowledge Graph & Decision Engine

[![Full-Stack CI/CD Pipeline](https://github.com/ShamalDave28/adaptive-decision-tree-engine/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/ShamalDave28/adaptive-decision-tree-engine/actions/workflows/ci-cd.yml)

A full-stack expert deduction engine powered by dynamic binary decision trees, runtime self-learning, and semantic NLP validation.

Built with a decoupled microservice architecture featuring a **FastAPI** REST backend, a **Streamlit** interactive UI, and persistent document storage in **MongoDB**.
